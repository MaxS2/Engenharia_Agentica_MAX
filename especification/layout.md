# Projeto: PPTNC Poke Deck

## Resumo: Projeto pedagógico criado para o podcast PPT Não Compila. O look'n feel deve ser divertido, mas ainda sim parecer profissional e seguir a identidade visual do podcast.

** IMPORTANTE: ** Toda interface e resultados da API deve conter somente elementos de texto em PT-BR.

## Referências:

    - Logotipo do podcast: ./especification/files/logo_quadrado.png
    - Mascote do Podcast (IAra): ./especification/files/IAra.png

## Telas

    1. Login: Login simples, padrão de usuário e senha.
        - Referência: ./especification/files/wireframe1.png

    2. Dashboard: onde o usuário vê os seus decks e os pokemons que estão dentro de cada um deles.
        - Os pokemons são exibidos em destaque.
        - Um menu lateral permite ao usuário criar novos decks e navegar entre eles.
        - Ao clica em um pokemon, ele vai para a ficha técnica desse pokemon.
        - Referência: ./especification/files/wireframe2.png

    3. Details: Onde o usuário pode ver todos os detalhes do Pokemon.
        - Ao clica em "Enviar a um amigo" o usuário pode escolher outro usuário do sistema para enviar o pokemon.
        - Referência: ./especification/files/wireframe3.png

    4. Gift Modal: Modal onde o usuário que vai receber o pokemon enviado vai escolher aceita o presente.
        - Modal é apresentado sobrepondo o dashboard ao logar.
        - Referência: ./especification/files/wireframe4.png

    5. Se o usuário for admin, ele terá um link e uma tela adicional pode poderá adicionar novos usuários.
        - Não é necessário wireframe para essa tela.

    6. Use sempre que possível imagens com boa resolução.
