# Sprint 4: Autenticação e Gestão

## Objetivo
Implementar o sistema de segurança real, persistência de usuários e o painel administrativo.

## Escopo
- Segurança com JWT no Backend.
- Persistência em SQLite (User Entity).
- Lógica de Login e Proteção de Rotas no Frontend.
- CRUD funcional de usuários para Admin.

## Entregáveis
1. **Sistema de Login:** Autenticação funcional com persistência.
2. **Painel Admin:** Admin pode criar e deletar usuários reais.

- [ ] Criar um novo usuário e tentar logar com ele.
- [ ] Tentar acessar `/admin` com um usuário comum e ser bloqueado.
