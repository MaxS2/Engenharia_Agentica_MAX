# Sprint 5: Dashboard

## Objetivo
Implementar a gestão real de decks e a visualização dos pokémons pertencentes a cada um.

## Escopo
- Persistência de Decks no Backend.
- Funcionalidade de Criar/Remover Decks.
- Paginação real (4 pokémons por vez).

## Entregáveis
1. **Gestão de Decks:** Usuário pode ter múltiplos decks.
2. **Visualização Paginada:** Navegação funcional entre pokémons do deck.
