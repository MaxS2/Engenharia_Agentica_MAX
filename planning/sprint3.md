# Sprint 3: Mock Frontend

## Objetivo
Implementar a interface visual completa da aplicação utilizando dados estáticos para validar o layout e a experiência do usuário.

## Escopo
- Desenvolvimento de Componentes Base (UI).
- Implementação de todas as páginas (Layouts).
- Simulação de navegação e estados de UI (Modais, Sidebar).

## Entregáveis
1. **Protótipo Funcional:** Todas as telas navegáveis com dados estáticos.
2. **Fidelidade Visual:** Interface seguindo o `layout-details.md`.

## Validação Humana
- [ ] Validar responsividade em Mobile e Desktop.
- [ ] Verificar se o "Mascote IAra" e o logotipo aparecem corretamente.
